# 看板快照 · 数据契约

> 看板快照 JSON 是「Obsidian 单一事实源」与「微信小程序派生视图」之间唯一的契约层。
> 前端（小程序）与备用网页渲染器都只读这份 JSON，绝不反向写数。

## 一、生成链路

```
各 00-最新状况.md
  ├─ ## 看板数据       (科目掌握度/知识点/待测)
  └─ ## 任务池候选     (待出任务卡队列)
        │  export_snapshot.py 解析
        ▼
   看板快照 JSON  (snapshot.json)
        │  CloudSync.push_snapshot 推云库
        ▼
   云数据库 snapshot/current  ── getSnapshot 云函数 ──▶ 小程序
                                  drawTask 云函数（抽 task_pool）
```

## 二、快照 JSON 结构

```jsonc
{
  "generated_at": "ISO 时间（本地时区）",
  "data_as_of": "YYYY-MM-DD",
  "evidence_level_note": "🟢真题/🟡样卷/🔴未测 仅后台记录",
  "summary": {
    "subjects_scored_total": 450,
    "mastery_pct": 0.62,                 // 语数英均值（有值才平均）
    "predicted_score_150_each": {"语文": null, "数学": null, "英语": 27},
    "untested_300_note": "中考750中综合/道法/历史/体育等300分待测≠0分",
    "known_future_subjects": ["物理","化学","道法","历史","体育","跨学科"]
  },
  "subjects": [
    {
      "key": "english",
      "name": "英语",
      "status": "active",                 // active | pending
      "mastery_pct": 0.60,                // null = 未测
      "color": "blue",                    // green>0.8 | blue≥0.5 | yellow<0.5 | gray未测
      "weak_count": 4,                    // points 中 status=red/yellow 的计数
      "predicted_score_150": 27,          // null = 待测
      "key_hint": "最该补：完形填空（长语境类）",
      "points": [
        {"point":"完形填空·长语境","mastery_pct":0.20,"status":"red","evidence":"🟢真题"}
      ],
      "untested": ["听力30","口语10","作文20"]
    }
  ],
  "task_pool": {
    "updated_at": "ISO 时间（AI 最近一次重整）",
    "english": [ { "id","type","title","roi","delivered_at","card":{...} } ],
    "math":    [ ... ],
    "chinese": [ ... ]
  }
}
```

- `task_pool.<subject>` 直接以科目 key 为字段（不嵌套 `subjects`）。
- `card` 字段结构复用《06-今日内容交付规范》大字卡：
  - 词/单点型：`word_from / word_to / ipa / collocation / rule / how / why`
  - 考点型（数/语）：`point / rule / how / why`

## 三、Obsidian 端 YAML 契约块

每个学科 `00-最新状况.md` 末尾含两个幂等块（由 `pipeline/init_subject_blocks.py` 初始化）：

### `## 看板数据`
```yaml
subject_key: english
mastery_pct: 0.60
predicted_score_150: 27
weak_count: 4
key_hint: "最该补：完形填空（长语境类，约20%）"
points:
  - point: "完形填空·长语境"
    mastery_pct: 0.20
    status: red
    evidence: "🟢真题"
untested:
  - "听力30"
  - "口语10"
  - "作文20"
```

### `## 任务池候选`
```yaml
- id: en-01
  type: master
  title: "完形填空·长语境逻辑"
  roi: 0.95
  delivered_at: null          # 抽卡云函数 drawTask 回填 ISO 时间
  card:
    title: "完形填空·长语境逻辑"
    rule: "先通读抓主线，再按上下文选词"
    how: "①读首句定主题 ②空前后找线索 ③排除明显错项"
    why: "长语境类是英语当前最大确定性失分面"
```

> 铁律：数字只在 Obsidian 改；改完跑 `export_snapshot.py` 即同步到小程序，不存在第二数据源。
